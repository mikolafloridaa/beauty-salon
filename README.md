# Бюті

Сайт салону краси: фото інтер'єру, прайс, майстри і форма запису.

## Темна тема

У правому верхньому куті є кнопка **Темна тема**. Вона перемикає сторінку між світлим і темним оформленням. Повторне натискання повертає світлу тему. Вибір зберігається в браузері, тож після оновлення сторінки тема не скидається.
